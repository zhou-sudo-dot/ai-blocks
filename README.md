# AI 教學擴展積木（MakeCode Arcade）

給 WiFiBoy Arcade / OK:D51 使用的離線 AI 教學積木。不改教具、不改平台、不需網路。

| 檔案 | 內容 |  |
|---|---|---|
| maze-ai.ts | 迷宮 AI（強化學習 Q-learning） | |
| shape-ai.ts | 圖形 AI（8×8 畫圖分類，最近中心法） | |
| tree-ai.ts | 決策樹 AI（監督式學習） |  |
| mango-game.ts | 遊戲「芒果小學徒 MANGO AI」（用 tree-ai 積木製作） | 課堂主打遊戲，也是範例 |
| test.ts | 擴展專案內的示範，`DEMO` = 1、2、3 切換 | 開發測試 |

## 安裝

1. 把整個資料夾上傳到 GitHub 公開儲存庫。
2. 在 MakeCode Arcade 工具箱按「擴展」，貼上儲存庫網址，會出現「迷宮 AI」「圖形 AI」「決策樹 AI」三組積木。
3. 想直接玩遊戲：用「匯入 → 匯入網址」打開這個儲存庫本身，`test.ts` 預設 `DEMO = 3` 會啟動芒果遊戲。
4. 想在自己的專案用遊戲：新增專案 → 加入擴展 → 切到 JavaScript，把 `mango-game.ts` 全部貼進 main.ts，最後一行寫 `mangoGame.start()`。

## 遊戲：芒果小學徒（對應課本 4-2 監督式學習、4-3 決策樹）

故事：爺爺有一套「祕密規則」分愛文芒果，你要把規則教給機器人 AI 學徒，再當品管員檢查它。

1. **教學**：芒果一個一個上輸送帶，按 ← A、↑ B、→ C 分級。爺爺會說對或錯，AI 同時把「標準答案」記下來。按 ↓ 結束教學（至少教 4 個）。
2. **學習**：AI 把範例長成一棵決策樹，並畫在螢幕上。
3. **檢查**：AI 上工，每顆芒果上方會顯示 AI 的分級。AI 錯了就按 A 喊「停」，抓到加 10 分；AI 其實對了還喊停扣 5 分；漏掉錯誤會扣一顆愛心。
4. **成績**：長條圖顯示每一輪 AI 的準確率。**資料越多，AI 越準**；整輪全對，AI 畢業，遊戲重新開始。

芒果的三個特徵：大小（大＝重）、顏色（紅／黃）、斑點（有／無）。規則與課本分級表一致：有斑點為 C；沒斑點且紅且大為 A；其餘為 B。

模擬結果（隨機教 n 個、8 種芒果各出現一次）：教 4 個平均約 80%、教 6 個約 92%、教滿 8 種就是 100%。所以一般兩到三輪就能畢業，一輪遊戲約 3～4 分鐘。

### 課堂可延伸的討論

- 教的芒果太少時，AI 為什麼會分錯？（資料量）
- 如果爺爺（老師）教錯答案，AI 會變怎樣？（標準答案的品質）
- 決策樹第一個問的問題是什麼？為什麼是它？（對應課本「選取特徵的順序」）
- 改規則後（例如改成看重量優先），AI 的樹會怎麼變？（修改 `truthOf` 函式，高年級挑戰）

## 決策樹 AI 積木（tree-ai.ts）

- 3 個特徵，每個特徵 0 或 1；答案 0、1、2 三種。
- 流程：清除 → 設定特徵名稱 → 給 AI 範例（特徵＋標準答案）→ AI 開始學習 → AI 判斷 → 把決策樹畫在背景。
- 建樹方式：每一步挑「分完最不混亂」的特徵（吉尼不純度），不需要複雜數學。

## 迷宮 AI 與圖形 AI

使用方式請看各檔案內的積木說明。迷宮 AI：設定迷宮 → 訓練 → 畫出箭頭 → AI 角色走一次。圖形 AI：畫圖 → 存成類別 → 開始訓練 → AI 判斷與把握程度 → 看 AI 心中的樣子。

## 已知限制

- 遊戲機內建字型只能顯示英文與數字，畫面文字用英文縮寫與圖示（例如 SIZE、COLOR、SPOT）。若要全中文介面，可把常用詞做成圖片素材，需要另外製作。
- 積木上的中文只出現在編輯器。
- 迷宮固定 8×8；決策樹固定 3 個二元特徵。
- 圖形 AI 的「把握程度」是各類相似度的相對比例，不是統計機率。

## 驗證狀態與上機前必測清單（重要）

已完成：
- 以 TypeScript 編譯器對照簡化的 Arcade API 做過語法與型別檢查，無錯誤。
- 決策樹、迷宮 Q-learning、圖形分類三個演算法，都用獨立程式驗證過邏輯（決策樹教滿 8 種芒果為 8/8 正確；迷宮約 50～100 回合收斂）。

**尚未**在 MakeCode 編輯器與 OK:D51 實機執行。請依序確認：

1. 匯入後無編譯錯誤，積木分組與中文顯示正常。
2. `test.ts`（DEMO = 3）：教學、學習、檢查、成績四個畫面都能走完，按鍵反應正常。
3. 芒果的大、小、紅、黃、斑點在螢幕上是否容易分辨（可調整 `mangoImage` 的尺寸與顏色）。
4. 音效名稱（`music.baDing` 等）、`sprite.sayText`、`image.doubledFont` 在你的 MakeCode 版本是否可用，不可用時依編譯訊息替換。
5. 實機的速度與記憶體（尤其是顯示決策樹與訓練 1000 回合時）。
